Device configuration for Infinix Hot 50 4G
=========================================

The Infinix Hot 50 4G (codenamed _"X6882"_) is a unpotential phone from Transhit.

It was announced in September 2024.

## Device specifications

Basic   | Spec Sheet
-------:|:-------------------------
CPU     | Octa-core (2x2.2 GHz Cortex-A76 & 6x2.0 GHz Cortex-A55)
Chipset | Mediatek Helio G100 (6 nm)
GPU     | Mali-G57 MC2
Memory  | 6/8 GB RAM
Shipped Android Version | Android 14, XOS 14.5
Storage | 128GB/256GB (UFS 2.2)
Battery | Non-removable Li-Po 5000 mAh
Display | IPS LCD, 120Hz, 1080 x 2460 pixels (~396 ppi density)
Camera  | 50/8 MP 1440p@30fps, 1080p@30/60fps, Selfie LED flash
